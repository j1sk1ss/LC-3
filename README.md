# LC-3 on CPL

This is Little Computer 3 Virtual Machine entirely written in CPL.

## Run

To build and run this project, use the `Makefile`:

```bash
make run
```

## Dependencies

To run this project you will need `cplc` with version `>= 3.8.6:2909.26`. To get this compiler, use [this](https://github.com/j1sk1ss/CordellCompiler) link or [link](https://github.com/j1sk1ss/CordellCompiler/releases/tag/v3.8) to releases.
